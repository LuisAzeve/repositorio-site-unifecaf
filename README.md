
# 📚 Biblioteca Digital UniFECAF

Este projeto foi desenvolvido como parte de um **trabalho da disciplina de Design Web da UniFECAF**.

A proposta foi criar uma interface para uma biblioteca digital fictícia, pensando em como apresentar livros, categorias e informações de forma organizada, bonita e fácil de navegar.

A ideia foi transformar a proposta do trabalho em um site que tivesse uma identidade visual própria e que funcionasse tanto em computadores quanto em celulares.

## 🌐 Acesse o projeto

* **Site publicado:** https://biblioteca-unifecaf-luis.netlify.app
* **Repositório:** https://github.com/LuisAzeve/repositorio-site-unifecaf/tree/main

## 🎯 Objetivo do projeto

O principal objetivo foi colocar em prática os conhecimentos de HTML e CSS, criando uma página web com uma aparência agradável, uma boa organização das informações e uma navegação simples para o usuário.

Além disso, o trabalho foi uma oportunidade de praticar a criação de layouts, a escolha de cores e elementos visuais e a adaptação do site para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

* **HTML5:** estruturação do conteúdo da página.
* **CSS3:** estilização, cores, layout e responsividade.
* **Netlify:** publicação do site na internet.
* **GitHub:** armazenamento e organização do código-fonte.

## ✨ Sobre o site

O site foi pensado para representar uma biblioteca digital de forma moderna e intuitiva, reunindo informações e elementos visuais relacionados ao ambiente acadêmico.

Durante o desenvolvimento, a proposta foi trabalhar principalmente com:

* Organização visual das seções;
* Identidade visual inspirada na UniFECAF;
* Apresentação dos conteúdos de forma clara;
* Layout adaptável para computadores e smartphones;
* Organização e separação dos arquivos HTML e CSS.

## 📱 Responsividade

Um dos pontos importantes do trabalho foi pensar em como o site seria exibido em diferentes dispositivos.

A proposta é oferecer uma experiência de navegação confortável tanto em telas maiores quanto em celulares, adaptando os elementos da página conforme o tamanho da tela.

## 📖 Sobre o trabalho

Este projeto tem finalidade acadêmica e foi desenvolvido como atividade prática da disciplina de Design Web.

Mais do que apenas montar uma página, a ideia foi aprender na prática como estruturar e estilizar um site, testar escolhas visuais e entender melhor o processo de desenvolvimento de uma interface web.
